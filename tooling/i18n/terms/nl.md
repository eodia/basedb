# nl — UI terms chosen while translating the docs (keep the app consistent with them)

- modèle → sjabloon (Databasesjabloon); galerie des modèles → sjablonengalerie; requête → query (plural query’s); vue SQL → SQL-view.
- recherche / cumul / décompte (field types, in prose) → opzoekveld / aggregatie / aantal.
- flux → flow; consigne → instructie; fournisseur d’IA → AI-provider; brouillons → concepten; tenant → werkruimte; purge → definitieve verwijdering; valeur d’affichage → weergavewaarde.
- Affichage (field format section) → Opmaak; « Plusieurs lignes par enregistrement » → Meerdere rijen per record.
- Chart types: Getal, Trend, Voortgang, Meter, Kolommen, Staven, Lijn, Vlakken, Combinatie, Cirkel, Trechter, Spreidingsdiagram, Tabel, Draaitabel, Landkaart (Kaart = card).
- Nieuwe database, Nieuwe SQL-query, Opslaan als weergave, Lezen van gegevens toestaan, Link actief, Insluiten in een andere site toestaan, Meer acties, Alle gebruikers / Beheerders (built-in groups).
- Typography: “…” with ‘…’ inside.
