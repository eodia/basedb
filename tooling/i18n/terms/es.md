# es — UI terms chosen while translating the docs (keep the app consistent with them)

- "disparador" for PostgreSQL triggers ("desencadenador" for automations); "agenda" for a calendar app (Calendario = the view); "feed de agenda"; Google Calendar.
- "Deshacer" for undo and Ctrl+Z; "Cancelar" only for cancel buttons.
- «Miembros conectados», «Enlace activo», «Permitir la inserción en otro sitio web», «código de inserción», «Nombre y uso compartido…», «Más acciones», «Tokens de API y MCP…», «Propuestas de los agentes…».
- Charts: «Ajustes» for Réglages, «Medidor», «Dispersión», «Sectores», «Tabla dinámica», «Detallar por semana», «Desglosar por…».
- Automations: «Colocar en el flujo», «Modificar una fila». badge → insignia; chips → píldoras; avis → reseñas.
- tenant stays "tenant" in technical contexts, "espacio de trabajo" for the people in it. Quotes «» without inner spaces, “” nested.
