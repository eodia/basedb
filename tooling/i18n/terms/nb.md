# nb — UI terms chosen while translating the docs (keep the app consistent with them)

- Undo « Annuler » → „Angre”; cancel buttons → „Avbryt”.
- PostgreSQL schema → „skjema”/„PostgreSQL-skjema” (careful: Skjema is also Formulaire).
- Charts: Stolper, Liggende stolper, Linje, Område, Kombinert, Sektor, Trakt, Punktdiagram, Krysstabell; map → Kart (Kort = card).
- Chart « Réglages » → „Oppsett”; field « Affichage » → „Visningsformat”.
- « Plusieurs lignes par enregistrement » → Flere rader per post; demo base → demodatabasen; purge → permanent tømming; « Mes vues » → Mine visninger.
- Innloggede medlemmer, Aktiv lenke, Tillat lesing av dataene, Tillat innbygging på et annet nettsted; tokens → Tokener.
- Typography: «» without inner spaces, ‹› nested, spaced en dashes, no space before colons.
