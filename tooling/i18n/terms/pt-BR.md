# pt-BR — UI terms chosen while translating the docs (keep the app consistent with them)

- "Buscar…" for the search box and the "Buscar uma linha" automation step (so it doesn't clash with Pesquisa = lookup field).
- "Ajustes" for Réglages (kept apart from Configurações = Paramètres).
- "Desfazer" for undo (Ctrl+Z); "Cancelar" for cancel buttons.
- "Copilot" also for the lowercase « copilote ».
- "trigger" for PostgreSQL déclencheurs; "Gatilho" only for automations.
- "Mapa" for the Carte visualization (geographic map), not Cartão.
- Chart names: Número, Tendência, Progresso, Medidor, Curva, Pizza, Funil, Dispersão, Tabela dinâmica.
- "instrução" for consigne; "provedor" for fournisseur; "webhook de entrada" (Slack).
- "Regenerar (link)", "Link ativo", "Membros conectados", "Permitir incorporação em outro site".
- "Minhas visões", "Salvar como visão/modelo", "Nova consulta SQL", "Criar visão SQL…", "Editar base…", "Outras ações", "Comparar ambientes…", "Propostas dos agentes…", "API e agentes", "Tokens de API e MCP…", "Documentação de API e MCP", "Nome e compartilhamento…", "Suas permissões", "Chave de sincronização".
- "banco"/"banco de dados" for the PostgreSQL database; "base" for a basedb base.
