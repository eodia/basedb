# ja — UI terms chosen while translating the docs (keep the app consistent with them)

- Pages: クイックスタート (Premiers pas); AI; REST API; 直接SQL; ロードマップ; 系統 (lignée).
- Menus: サイドバー; APIとエージェント; APIとMCPのトークン…; APIとMCPのドキュメント; エージェントの提案…; その他の操作; データベースを編集…; 環境を比較…; マイグレーションを適用…; 行の同期.
- Views and fields: マイビュー; 個人ビューを作成; ビューとして保存; 行の高さ (低/中/高/特大); 複数の行をリンク; 依存先 (Dépend de); フィールドを挿入; 表示 (Affichage).
- Templates: テンプレート / テンプレートギャラリー / デモデータベース; テンプレートとして保存.
- Sharing: 公開 / ログイン済みメンバー; リンク有効; リンクを再生成; 共有を停止; 他のサイトへの埋め込みを許可.
- SQL and Copilot: 自分の権限 (the « Vos droits » badge); データの読み取りを許可; 新しいSQLクエリ; SQLビューを作成…; 名前を付けて保存…; 名前と共有….
- Automations: 行が作成されたとき / 行が更新されたとき / 決まった時刻 / ボタンがクリックされたとき; 行を更新 / 行を作成 / 行を検索 / メンバーに通知 / Webhookを呼び出す / Slackに送信 / 条件; 期待する回答, フローに配置, 行でテスト, 実行 tab; statuses 待機中 / 実行中 / 成功 / スキップ / 失敗.
- Dashboards: 数値, トレンド, 進捗, ゲージ, 縦棒グラフ, 横棒グラフ, 折れ線グラフ, 面グラフ, 複合グラフ, 円グラフ, ファネル, 散布図, 表, クロス集計表, 地図 (not カード); 表示設定 (Réglages; 設定 = Paramètres); データを探索, データを結合, 件数制限, 埋め込みページ, 見出し, 対応するすべてのカードに接続.
- Synced tables: 同期キー, 「同期」 badge.
- Undo → 元に戻す; Cancel → キャンセル; Ctrl+Shift+Z.
