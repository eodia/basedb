一行可以变成一份 **PDF**：带有明细和总计的发票、报价单、送货单、产品资料表，或一份证明。在行详情中，**PDF 文档**按钮会在新标签页中打开它，随后可以用浏览器打印或保存。

## 不做任何设置的详情页

没有模板时，一行会以**详情页**的形式打印：标题是它的名称，随后是您可以读取的所有字段，使用您的界面语言。

## 创建模板

构建该数据表的人——可管理级别——从一行的行详情中创建模板：**PDF 文档 › 文档模板…**。新模板从一个**起点**开始：

| 起点 | 预设内容 |
|---|---|
| **发票** | 带徽标和联系方式的页眉、“发票”字样、编号和日期；客户信息；开票项目及其总计；含税/不含税汇总；付款条件；页脚中的法律声明 |
| **报价单** | 彩色横幅上的标题、网格排列的信息、服务项目、有效期、“签字确认”区域 |
| **资料表** | 通栏大标题、图片字段的照片、网格排列的字段、长文本 |
| **证明** | 带边框的横向页面、居中文字、签名 |
| **空白页面** | 标题和行字段 |

它由**您数据表的列**构成——编号、日期、金额、照片，以及与之关联的行——数据表没有的内容则直接省略。之后一切都可以更改；右侧的预览会显示当前打开行的 PDF，并随每次修改自动更新。

## 内容：区块

区块从上到下依次排列；可以通过拖动其**手柄**来调整顺序，点击展开即可进行设置。

| 区块 | 显示内容 |
|---|---|
| **标题** | 一个大标题和一个副标题，样式可选简约、彩色、下划线，或通栏横幅——横跨整页宽度 |
| **文本** | 富文本——标题、粗体、列表、链接——可通过**列**菜单引用该行的列：“发票 `{{numero}}`，日期为 `{{date}}`”；可选**左对齐**或**两端对齐**，可设置**浅色背景**、**带边框**，或用一条彩色竖线标记 |
| **图片** | 徽标、印章，或该行图片字段中的照片 |
| **行字段** | 所选的字段，或全部字段：标签在左，或标签在上、以 2 或 3 列的网格排列，或**摘要**——数值靠右，最后一项（应付金额）为粗体；空字段可以隐藏 |
| **关联行表格** | 指向这一行的行——如一张发票的明细行——或某个多项关联所指向的行，并显示它们的**总计**；表头可上色，可**隔行加底色**，表头文字、列宽和对齐方式均可自行调整（例如将“Quantité”简写为“Qté”） |
| **列** | 两列或三列并排显示，每列各有自己的区块：一侧放“收件方”，另一侧放参考信息 |
| **分隔符**、**间距** | 一条线——短线可用于预留签名位置——或一段空白 |
| **分页符** | 后续内容另起一页 |

## 样式与页面

- **强调色**——您品牌的颜色：标题、横幅、表头、链接。叠加在上面的文字会根据可读性自动显示为白色或深色。
- **文字颜色**、文本与标题的**字体**（黑体或宋体）、文字**大小**、**小标题**样式。
- **页面大小**（A4 或 Letter）、**方向**、**页边距**，页面周围的单线或双线**边框**，内容**在页面上垂直居中**——用于证明文件。
- **取值使用的语言**：金额带上货币符号（"1 234,50 €"），日期写成完整形式（"2026 年 9 月 30 日"），是与否、选项的标签、人员的姓名皆是如此。文本使用内置字体排版，覆盖 basedb 的全部二十种语言，包括各类表意文字。

## 页眉和页脚

**页眉**包含您的**徽标**——上传的图片（PNG、JPEG 或 SVG；过大的图片会被压缩）或该行某个图片字段——左侧的一段文字（您的联系方式）和右侧的一段文字（文档类型、编号、日期），显示在首页或每一页上。**页脚**包含您的法律声明和页码。两者都可以像文本一样引用该行的列。

## 各自持有的权限

一份文档以**打印者的权限**读取：对他隐藏的字段不会出现在文档中——既不会出现在文本里，也不会出现在图片里——他看不到的关联行不会出现在表格里——合计也不包括它们。因此，同一行可能会为两个人生成两份不同的文档：各自看到自己权限内的内容。

## 通过 API

```bash
# 用模板生成一行的 PDF，即“详情页”
curl -H "Authorization: Bearer $TOKEN" -o facture.pdf \
  "$BASEDB/api/v1/$TENANT/data/ventes/factures/$ID/documents/$MODELE"
```

`GET …/data/{base}/{table}/documents` 列出该数据表的模板。

## 限制

- 上传的图片最大 300 KB，每个模板最多八张；字段中的图片仅当为 PNG 或 JPEG 格式时才会被采用。
- 关联行以外的某个值，需要通过文档所在数据表上的**查找引用**字段来引用；含税总额则是数据表中的一个字段。
- 一份文档对应一行：暂不支持多行合并生成 PDF。[自动化](/basedb/zh-cn/fonctionnalites/automatisations/#pdf-与邮件)可以代您完成——**生成 PDF**——并将其作为附件发送。
