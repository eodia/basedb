title: PDF 文档
description: 把一行变成发票、报价单或可打印的详情页，包含关联行和合计。
---

一行可以变成一份 **PDF**：带有明细和总计的发票、报价单、送货单，或是一份详情页。在行详情中，**PDF 文档**按钮会在新标签页中打开它，随后可以用浏览器打印或保存。

## 不做任何设置的详情页

没有模板时，一行会以**详情页**的形式打印：标题是它的名称，随后是您可以读取的所有字段，使用您的界面语言。

## 模板

构建该数据表的人——可管理级别——从一行的行详情中编写模板：**PDF 文档 › 文档模板…**。一个模板由一页（A4 或 Letter，纵向或横向）、值所使用的语言、一个页脚和一系列区块组成：

| 区块 | 显示内容 |
|---|---|
| **文本** | 富文本——标题、粗体、列表、链接——可通过**列**菜单引用该行的列："发票 `{{numero}}`，日期为 `{{date}}`" |
| **行字段** | 所选的字段，或全部字段：左边是标签，右边是值 |
| **关联行表格** | 指向这一行的行——如一张发票的明细行——或某个多项关联所指向的行，包含所选的列及其**合计** |
| **分页符** | 后续内容另起一页 |

编辑器会在旁边实时显示该模板对当前打开的行生成的 PDF，包括尚未保存的修改。

值会按**模板所选的语言**书写：金额带上货币符号（"1 234,50 €"），日期写成完整形式（"2026 年 9 月 30 日"），是与否、选项的标签、人员的姓名皆是如此。文本使用内置字体排版，覆盖 basedb 的全部二十种语言，包括各类表意文字。

## 各自持有的权限

一份文档以**打印者的权限**读取：对他隐藏的字段不会出现在文档中，他看不到的关联行不会出现在表格里——合计也不包括它们。因此，同一行可能会为两个人生成两份不同的文档：各自看到自己权限内的内容。

## 通过 API

```bash
# 用模板生成一行的 PDF，即"详情页"
curl -H "Authorization: Bearer $TOKEN" -o facture.pdf \
  "$BASEDB/api/v1/$TENANT/data/ventes/factures/$ID/documents/$MODELE"
```

`GET …/data/{base}/{table}/documents` 列出该数据表的模板。

## 限制

- 文档中不支持图片（徽标）或自定义颜色，页眉也无法与页脚区分设置。
- 一份文档对应一行：暂不支持多行合并生成 PDF，也不支持由自动化生成。
