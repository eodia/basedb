顶部工具栏中央的<strong>搜索数据表、行、命令…</strong>输入框会打开搜索：一个输入框即可找到 basedb 中您能访问的一切。**Ctrl+K**（Mac 上为 **⌘K**）可以在任意屏幕打开或关闭它——富文本编辑器中除外，此时它会插入一个链接。

## 它能找到什么

| | |
|---|---|
| **数据表和对象** | 您能看到的项目和数据库；数据表、SQL 视图和已保存的查询；已打开数据库中各数据表的视图，包括个人视图；项目中各数据库的问题、仪表盘和自动化；数据表的列；已打开的标签页 |
| **行** | 已打开数据库的数据表中的数据本身：列中的文本、选项列表中的选项、精确的数字——最少两个字符起。粘贴一个行标识符即可找到对应的行 |
| **命令** | 应用能做的事：前往结构、历史记录、数据库的仪表盘；新建数据表、问题、SQL 查询、数据库、项目，或从模板开始；向数据表导入数据；撤销或重做最近一次写入；关闭或切换标签页；切换主题；打开 Copilot；**复制此页面链接**；打开设置或管理后台的某个标签页；退出登录 |
| **Copilot** | 交给 Copilot 处理的一句自然语言问题 |

**Enter** 打开所选结果：一行会在其数据表中的详情里打开。在大屏幕上，右侧面板会显示预览——一行的各个值，一张数据表的列和描述，或一个仪表盘、一个自动化的描述。粘贴一个 basedb 地址：**打开此链接**会带您前往（参见[指向每个屏幕的链接](/basedb/zh-cn/fonctionnalites/collaboration/#指向每个屏幕的链接)）。

输入框为空时，会显示您的**最近使用**、已打开的标签页、当前数据库的数据表和一些建议。

## 想到什么就打什么

- **不区分重音符号和大小写**：这类差异出现在拉丁字母的名称中，对中文本身没有影响。
- **只输入开头也可以**：`新客` 能找到“新客户”，`自动` 能找到“自动化”。
- **容忍一次打字错误**——遗漏、重复、打错或颠倒一个字母，七个字母以上的单词允许两处错误——但第一个字母不能错。
- **输入的每个词都必须能在某处找到**，无论是在名称本身还是在包含它的对象中：`销售 客户` 能找到数据库“销售”中的数据表“客户”。类型词也可以输入：`视图`、`自动化`、`仪表盘`。
- **先输入数据表，再输入要查找的内容**：`客户 成都` 会在数据表“客户”的各行中查找“成都”。

列表最前面是**最佳结果**：您经常打开、最近打开的内容会排在前面。这份记录只保存在您的浏览器中。

## 缩小搜索范围

输入框下方的选项——**全部**、**数据表和对象**、**行**、**命令**、**Copilot**——用于限定搜索范围。输入的第一个字符也能起到同样的作用：

| 先输入 | 用于查找 |
|---|---|
| `#` | 仅数据表和对象 |
| `/` | 仅行 |
| `>` | 仅命令 |
| `?` | 向 Copilot 提问 |

在一张数据表或一个数据库上按 **Tab** 键，会**进入其中**搜索：其名称显示在输入框中，搜索范围也随之只限于它的行、视图、列和命令。此时清空输入框会显示最近修改的二十行。在输入框为空时按 **⌫** 可以退出；按 **Esc** 则先后退一步，再关闭搜索。

## 询问 Copilot

每次搜索的结果末尾都会出现**询问 Copilot：“……”**；当输入的文本读起来像一个问题时——以“？”结尾，以“多少”“哪个”“显示”等开头，或者达到五个词以上——它会排在最前面。Copilot 会在当前数据库中打开，并像您亲自输入一样接收这个问题。它只读取结构，不读取行数据，除非您勾选**允许读取数据**；它提出建议，在您应用之前不会改变任何内容。这需要实例上已配置好 AI——参见[人工智能](/basedb/zh-cn/fonctionnalites/ia/)。

## 权限与限制

搜索使用的是与界面其余部分相同的接口，**并按您的权限执行**：对您关闭的数据表或列，既不会出现在对象中，也不会出现在行里。只有对相应数据库拥有**可管理**级别的人，才会看到自动化。

- 行的搜索范围是当前打开的数据库，或您通过 Tab 进入的数据库或数据表：每张数据表最多三行，最多涵盖二十四张数据表；进入某张数据表后则最多二十行。
- 问题、仪表盘和自动化取自当前打开的项目（最多八个数据库），最多每两分钟重新读取一次。
- 每组结果先显示少量结果，随后是**还有 N 个结果**，点击即可查看全部。

## 键盘快捷键

点击搜索框底部的**快捷键**，或使用**键盘快捷键**命令，可以查看全部快捷键。**Ctrl** 在 Mac 上读作 **⌘**。

| 按键 | 作用 |
|---|---|
| **Ctrl+K** | 打开或关闭搜索 |
| **↑** **↓**、**Enter** | 浏览结果、打开结果 |
| **Alt+W** | 关闭标签页 |
| **Ctrl+Tab**、**Ctrl+Shift+Tab** | 下一个标签页、上一个标签页 |
| 鼠标中键点击 | 关闭一个标签页 |
| **Ctrl+A**、**Ctrl+C** | 在网格中：全选、复制所选单元格 |
| **Ctrl+点击** | 跟随一个关联 |
| **Ctrl+Z**、**Ctrl+Y** | 撤销最近一次写入、重做 |
| **Ctrl+Enter** | 发送评论、保存描述 |
| **Ctrl+B**、**Ctrl+I**、**Ctrl+K** | 在文本中：加粗、斜体、链接 |
