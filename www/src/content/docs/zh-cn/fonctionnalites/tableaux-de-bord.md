**仪表盘**将团队每天关注的内容汇集在一个页面上：关键数字、逐月变化、某个状态的分布、即将到来的截止日期。其中每张卡片展示一个**问题**——对数据库的一次读取，用鼠标构建或用 SQL 编写——页面顶部的**筛选**控制与之关联的卡片。

![“Pilotage de l’agence”仪表盘：本月趋势、目标、堆叠显示的营业额、评价情绪](../../../../assets/screens/tableaux-de-bord.png)

一切都从侧边栏底部当前数据库区块中的**仪表盘**入口打开。左侧列出该数据库的仪表盘和已保存的问题，以及**探索数据**，可在不保存任何内容的情况下提出问题。数据库的所有读者都可以查看、探索，并保存自己的问题；搭建仪表盘和共享问题则需要**可管理**级别。

已保存的问题可以是**个人**的——只有您自己能看到——也可以共享给**整个数据库**或**指定用户组**。它的菜单（右键点击或 **⋯**）可以在与数据表并列的标签页中打开它、更改它的名称和共享范围，或将其删除。标签栏的 **+** 还提供**新建问题**和**新建 SQL 问题**。

**保存**位于问题的标题栏中，用于保留当前问题；如果您无权修改某个问题，标题栏会改为提供**保存副本**，副本将归您所有。**⋯**（**更多操作**）还提供**名称和共享…**、**保存副本…**和**删除问题**；曾经显示该问题的标签页会保留其内容，但会变回未保存状态。

## 用鼠标提出问题

问题按步骤自上而下构建：

![问题编辑器：数据、筛选条件、按月统计](../../../../assets/screens/question-editeur.png)

| 步骤 | 选择内容 |
|---|---|
| **数据** | 起始数据表，以及不做统计时显示的列 |
| **连接数据** | 数据库中的另一张数据表，通过关联（会自动建议）或两个同类列连接；左连接、内连接、右连接或全连接 |
| **筛选** | 按列筛选，可用条件取决于列的类型：是 / 不是、包含、介于、为空……；日期可选**时间段**：今天、最近 30 天、本月、上季度、从……到……；也可以像在视图工具栏中一样书写表达式 |
| **统计** | 度量——行数、总和、平均值、中位数、最小值、最大值、去重计数、标准差、累计值——**按**一到三列统计 |
| **排序**、**限制** | 行的顺序，以及最多返回多少行 |

日期可以**按日、周、月、季度或年**分组，也可以按序位分组——星期几、月份、一天中的小时；数字可以分段。多选字段会将每行计入其每个选项。时间段按您的时区解读，一周从您设置中指定的那一天开始。

**可视化**会运行问题。结果会以合适的方式展示——一个数字、一条曲线、若干条形、一张表格——并可在屏幕底部切换：

| 可视化 | 用于展示 |
|---|---|
| **数值**、**趋势**、**进度**、**仪表** | 一个值；最近一个时间段与上一个时间段及去年同期的对比；朝目标的进展 |
| **柱状图**、**条形图**、**折线图**、**面积图**、**组合图** | 沿某个维度的度量，系列可并排、堆叠或按 100% 堆叠 |
| **饼图**、**漏斗图** | 占比、阶段 |
| **散点图** | 两个度量相互对照，第三个度量用点的大小表示 |
| **表格**、**交叉表** | 可排序的行；按一个维度分行、按另一个维度分列，并附合计 |
| **地图** | 法国的大区或省，或世界各国，按数值着色；或按经纬度标注的点 |

**设置**用于调整显示内容，结果可下载为 **CSV**。

### 自定义图表

| 可视化 | **设置**中提供的选项 |
|---|---|
| **条形图、折线图、面积图、组合图** | 每个系列的颜色和名称；堆叠方式，以及堆叠顶部的合计；条形宽度；平滑或阶梯折线，带或不带数据点；类别顺序；坐标轴标题、刻度、标签倾斜角度、上下限、对数刻度；在图上显示数值；目标线 |
| **饼图** | 环形图及其粗细、半圆、玫瑰图；中心显示合计；归入“其他”之前的扇区数量；每个扇区的颜色和名称；标签显示在扇区上或旁边；图例位置 |
| **漏斗图** | 每个阶段的颜色和名称，以及阶段顺序 |
| **数值、趋势、进度、仪表** | 颜色、按数值变化的颜色、数字下方的说明、对比方式——以及下降是否算好消息 |
| **表格、交叉表** | 重命名列并调整顺序、单元格内条形、按数值着色（按单元格或按行）、密度、每页行数、行号、合计 |
| **地图** | 色调、地区名称 |

所有可视化都可设置数字格式：小数位数、前缀和后缀、缩写为 `1,2 k`。

## 一键探索

点击条形、数据点或扇区，即可打开它所代表的内容：

- **查看这些行**：该数据点背后的行，按其所代表的内容筛选；
- **按周细分**：将一个时间段展开为更细的粒度——一年展开为各季度，一个月展开为各周；
- **按…拆分**：针对该数据点，将同一度量按另一列拆分；
- **仅此值**、**排除此值**。

每一步都是一个独立的问题，可以按需保存；返回箭头会回到上一步。点击表格中的一行会打开其行详情。

在仪表盘上，同样的点击还会提供**筛选仪表盘：“Lyon”**，并显示受影响的卡片数量：这是一个**临时**筛选，从不保存，在筛选栏中以虚线显示，点击即可移除；它作用于所有问题读取同一列的卡片——无论是通过其数据表还是通过连接。只有当卡片上没有任何仪表盘筛选已关联到该列时才会提供此选项；如果没有其他卡片读取该列，则显示为灰色（“仅此卡片”）。SQL 问题不受其影响。

## 用 SQL 编写问题

**SQL 问题**是对数据库中数据表的一条 `SELECT` 语句，使用它们的真实名称。它**以只读方式、按您自己的权限**执行——对所有人都是如此，包括管理者：对您不开放的数据表并不存在，隐藏字段会被拒绝，写入也无法进行。如果只想把查询保存在数据表下方而不需要图表，或想将其变为真正的 PostgreSQL 视图，请参见[查询与 SQL 视图](/basedb/zh-cn/fonctionnalites/requetes-et-vues-sql/)。

**变量**写作 `{{nom}}`；没有值时需要去掉的部分，放在 `[[` 和 `]]` 之间：

```sql
SELECT statut, count(*) AS taches
  FROM taches
 WHERE {{periode}} [[AND priorite = {{priorite}}]]
 GROUP BY statut
```

变量可以是文本、数字、日期——也可以是**列筛选器**：此时 `{{periode}}` 会变成针对所选列（这里是 `echeance`）的完整条件，未选择任何值时则为 `TRUE`。正是这一点让仪表盘的筛选能够像控制其他问题一样控制 SQL 问题。

## 编排仪表盘

**编辑**会让仪表盘进入编辑模式：

- **问题**：放置一个已保存的问题（个人问题会被复制到其中），或新建一个仅属于该卡片的问题；
- **标题**添加章节标题，**文本**添加带格式的文本——标题、列表、链接——其中可以引用数字（见下文）；
- **嵌入页面**：在隔离的框架中显示一个 `https://` 地址，该框架不会收到任何会话或数据；
- **标签页**：将卡片分布到多个页面；双击可重命名标签页。

卡片可通过手柄移动，通过右下角调整大小，排布在 24 列的网格上。**保存**会保留全部修改；**取消**则返回之前的版本。在查看模式下，点击卡片标题会打开其问题以便探索，并带上仪表盘的筛选条件。

### 文本中的数字

文本可以用双花括号中的名称引用一个值：“本月的营业额为 `{{chiffre_affaires}}`，来自 `{{commandes}}` 笔订单。”每个名称都会变成一个小标签，点击一下——或通过编辑器工具栏中的**变量**——即可将其关联到：

| 来源 | 文本中显示的内容 |
|---|---|
| 仪表盘的**一张卡片** | 它所展示的内容，按其自身的筛选条件计算 |
| 整个数据库的**一个已保存问题** | 它的取值；仪表盘的筛选条件会像作用于卡片一样与之关联 |
| **保留在文本中的一个问题** | 它的取值；这正是引用个人问题的方式 |
| 仪表盘的**一个筛选** | 所选的值，如同其说明所描述的那样 |

问题的取值就是其**数值**可视化所显示的内容：最后一行上的第一个度量。它会按读者的权限计算，并始终以文本形式显示。一段文本最多可以引用 20 个取值；名称只能使用小写字母、数字和 `_`。在编辑器上线之前用 Markdown 编写的文本仍会照常显示，一经重新编辑就会变为富文本。Copilot 编写的文本则使用 Markdown。

## 筛选

**筛选**会在仪表盘顶部添加一个控件：**日期**（时间段）、**类别**（可勾选的值）、**文本**、**数字**，或**日期分组**——可让曲线在按月、按周或按年之间切换。

筛选控制与其关联的卡片——一张、多张或全部。创建时，它会自动关联到合适的列；选中它时，每张卡片上会显示它所筛选的列，可以更改或移除；**关联到所有兼容的卡片**会补全其余卡片。筛选可以设置**默认值**，例如“今年”。

在查看模式下，点击数据点也可以设置筛选：在城市列已关联到“Ville”筛选的卡片上，选择**按“Lyon”筛选**。

![“Activité”标签页：按截止日期、按状态堆叠的任务，项目漏斗，以交叉表显示的预估工时](../../../../assets/screens/tableaux-de-bord-activite.png)

## Copilot

仪表盘版块标题栏中的 **Copilot** 会在右侧打开一个对话，用自然语言讨论数据库：“每月营业额”、“添加一个按客户的筛选”、“为什么八月下降了？”。每个提议都以卡片形式出现，点击即可应用：

| 提议 | 作用 |
|---|---|
| **一个问题** | 在对话中执行并绘制；可在编辑器中打开，或添加到仪表盘 |
| **对仪表盘的修改**，或一个新仪表盘 | 添加、修改或移除卡片，文本，自动关联到含有相应列的卡片的筛选，标签页，名称——一次保存完成，可从卡片上**撤销** |
| **为当前筛选设置值** | “显示上个月的数据”：筛选会自动设置，不保存任何内容 |

提出问题或设置筛选对数据库的所有读者开放；修改或创建仪表盘需要**可管理**级别。

默认情况下，**只有结构**会与对话一起发送给 AI 服务商：数据表及其字段、数据库的仪表盘和已保存的问题，以及当前显示的仪表盘——它的标签页、筛选、卡片定义（其问题和文本）。不会发送行和卡片的结果，也不会发送**筛选中选定的值**，因为这些值可能就是数据：对于筛选，只会发送“它有值”这一事实。被标记为对智能体不可见的字段不会发送，引用该字段的卡片问题也不会发送。

勾选**允许读取数据**后，会在本次对话中额外发送当前筛选的值，以及这些筛选下卡片的结果（每次读取最多 50 行，列在回答下方），以便结合数字进行评述。参见[人工智能](/basedb/zh-cn/fonctionnalites/ia/)。

## 共享仪表盘

仪表盘标题栏中的**共享**仅对拥有该数据库**可管理**级别的人提供。有两种方式：

- **共享数据库…**：邀请他人加入数据库：他们在 basedb 中打开仪表盘，每张卡片都按他们自己的权限读取；
- **创建链接**：生成一个**仅**指向该仪表盘的链接，无需对数据库拥有任何权限。

| 链接访问方式 | 谁可以查看 |
|---|---|
| **公开** | 任何持有链接的人，无需账户 |
| **已登录成员** | 工作区成员，登录后查看——如有需要，可仅限特定用户组 |

链接页面**以只读方式**显示仪表盘的标签页、筛选和卡片：不能探索，不能访问行，也不能提出自己的问题。其卡片以**发布链接者的权限**读取，并在每次读取时重新判定：如果此人失去对数据库的访问权限，链接会被**暂停**。**启用链接**开关可关闭链接而不丢失它，**重新生成**会使旧链接失效。

勾选**允许嵌入其他网站**：对话框会提供一段 `<iframe>` **嵌入代码**，用于在内网或 Wiki 中显示仪表盘。其机制与[共享视图](/basedb/zh-cn/fonctionnalites/vues-partagees/)相同。

## 各按其权限

每张卡片都**按查看者的权限**读取：同一个仪表盘向每个人展示其有权看到的内容——通过共享链接查看时除外，此时按发布者的权限读取。如果卡片涉及对您不开放的数据表或字段，会显示“数据不可访问”，而不是一个因遗漏而失真的数字。保存问题只会共享问题本身，绝不会共享其作者能读取的内容。

## 限制

- 一个问题最多返回 2000 行；统计结果几乎总是足够。
- 每张卡片在打开时以及每次筛选时都会执行其查询，不使用缓存。
