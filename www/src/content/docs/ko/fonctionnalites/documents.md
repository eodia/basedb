행 하나가 **PDF**가 됩니다: 행과 합계가 있는 청구서, 견적서, 배송 확인서, 제품 시트,
증명서입니다. 행 세부 정보의 **PDF 문서** 버튼을 누르면 새 탭에서 열리고, 그 탭에서
브라우저가 인쇄하거나 저장합니다.

## 설정 없이 만드는 기본 문서

템플릿이 없으면 행은 **기본 문서**로 인쇄됩니다: 제목으로 행의 이름, 그다음 읽을 수 있는
모든 필드가 사용자 언어로 표시됩니다.

## 템플릿 만들기

테이블을 만드는 사람 — 관리 권한 — 이 행 세부 정보에서 템플릿을 만듭니다: **PDF 문서 ›
문서 템플릿…**. 새 템플릿은 **시작점**에서 출발합니다:

| 시작점 | 포함되는 내용 |
|---|---|
| **청구서** | 로고와 연락처가 있는 머리글, “청구서”, 번호와 날짜; 고객; 청구 항목과 그 합계; 공급가액/부가세 요약; 결제 조건; 바닥글의 법적 고지 |
| **견적서** | 색상 띠 위의 제목, 그리드 형태의 정보, 서비스 내역, 유효 기간, “승인” 구역 |
| **시트** | 전체 너비의 큰 제목, 이미지 필드의 사진, 그리드 형태의 필드, 장문 텍스트 |
| **증명서** | 테두리가 있는 가로 페이지, 가운데 맞춤 텍스트, 서명 |
| **빈 페이지** | 제목과 행의 필드 |

**테이블의 열**을 바탕으로 만들어집니다 — 번호, 날짜, 금액, 사진, 연결된 행 — 그리고
테이블에 없는 항목은 그냥 제외됩니다. 이후에는 모든 것을 바꿀 수 있습니다. 오른쪽의
미리보기는 열려 있는 행의 PDF를 보여 주며, 수정할 때마다 바로 반영됩니다.

## 내용: 블록

블록은 위에서 아래로 이어집니다. 손잡이를 잡고 **끌어서** 순서를 바꾸고, 블록을 눌러
설정을 엽니다.

| 블록 | 보여 주는 것 |
|---|---|
| **제목** | 큰 제목과 부제목. 단순하게, 색상으로, 밑줄로, 또는 페이지 끝까지 닿는 띠 형태로 |
| **텍스트** | 서식 있는 텍스트 — 제목, 굵게, 목록, 링크 — 로, **열** 메뉴로 행의 열을 인용합니다: “청구서 `{{numero}}` — `{{date}}`”; 정렬 또는 양쪽 맞춤, 색이 있는 배경, 테두리, 색상 바 표시 중에서 고를 수 있음 |
| **이미지** | 로고, 도장, 또는 행의 이미지 필드에 있는 사진 |
| **행의 필드** | 선택한 필드 전체 또는 일부: 왼쪽에 레이블을 두고 오른쪽에 값을 표시하거나, 위쪽에 레이블을 두고 2단 또는 3단 그리드로 표시하거나, **요약**처럼 값을 오른쪽에 두고 마지막 값(지불할 총액)을 굵게 표시할 수 있음; 빈 필드는 숨길 수 있음 |
| **연결된 행 표** | 이 행을 가리키는 행들 — 청구서의 각 줄 — 이나 다중 관계가 가리키는 행들을, 그 **합계**와 함께 표시; 색이 있는 머리글, 한 줄씩 교대로 음영 처리된 행, 열 머리글·너비·정렬은 직접 설정 가능(“수량”을 “수”로) |
| **열** | 나란히 놓인 2단 또는 3단, 각각 자신의 블록을 가짐: 한쪽에 “청구 대상”, 다른 쪽에 참조 정보 |
| **구분 기호**, **공백** | 선 — 서명란처럼 짧게 — 또는 빈 공간 |
| **페이지 나누기** | 다음 내용을 새 페이지에서 시작 |

## 스타일과 페이지

- **강조 색상** — 브랜드의 색상으로, 제목, 띠, 표 머리글, 링크에 사용됩니다. 그 위에
  놓이는 텍스트는 가장 잘 읽히는 쪽에 따라 흰색 또는 어두운 색이 됩니다.
- **텍스트 색상**, 본문과 제목의 **글꼴**(세리프 또는 산세리프), 텍스트 **크기**, 소제목
  스타일.
- **용지 크기**(A4 또는 Letter), **방향**, **여백**, 페이지 둘레의 단선 또는 이중
  **테두리**, 내용 **세로 중앙 정렬** — 증명서에 적합합니다.
- **값의 언어**: 금액은 통화와 함께(“1 234,50 €”), 날짜는 글로 풀어 써서(“2026년 9월
  30일”) 표시되며, 예/아니요, 선택 값의 레이블, 사람의 이름도 마찬가지입니다. 텍스트는
  basedb의 20개 언어를 모두 지원하는 내장 글꼴로 구성되며, 한자·가나·한글도 예외가
  아닙니다.

## 머리글과 바닥글

**머리글**에는 **로고**가 들어갑니다 — 업로드한 이미지(PNG, JPEG 또는 SVG; 너무 큰
이미지는 축소됨) 또는 행의 이미지 필드 — 그리고 왼쪽 텍스트(연락처 정보), 오른쪽
텍스트(문서 종류, 번호, 날짜)가 첫 페이지에만 또는 모든 페이지에 들어갑니다. **바닥글**에는
법적 고지와 페이지 번호가 들어갑니다. 둘 다 텍스트 블록처럼 행의 열을 인용할 수 있습니다.

## 각자 자신의 권한으로

문서는 **인쇄하는 사람의 권한으로** 읽힙니다. 그 사람에게 숨겨진 필드는 텍스트에도
이미지에도 나타나지 않고, 볼 수 없는 연결된 행은 표에도 합계에도 들어가지 않습니다.
그러므로 같은 행에서 두 사람이 서로 다른 두 개의 문서를 얻을 수 있습니다: 각자 자신의
문서를 받습니다.

## API로

```bash
# 템플릿으로 만든 행의 PDF, 또는 “기본 문서”
curl -H "Authorization: Bearer $TOKEN" -o facture.pdf \
  "$BASEDB/api/v1/$TENANT/data/ventes/factures/$ID/documents/$MODELE"
```

`GET …/data/{base}/{table}/documents`는 테이블의 템플릿 목록을 반환합니다.

## 제한

- 업로드하는 이미지는 최대 300KB이며, 템플릿당 최대 8개까지 사용할 수 있습니다. 필드의
  이미지는 PNG 또는 JPEG일 때만 사용됩니다.
- 연결된 행의 값을 표 바깥에서 인용하려면 문서의 테이블에 **조회** 필드를 추가해야
  합니다. 세액 포함 합계는 테이블의 필드로 만들어야 합니다.
- 행 하나에 문서 하나: 여러 행을 하나의 PDF로 만드는 기능은 아직 없습니다.
  [자동화](/basedb/ko/fonctionnalites/automatisations/#pdf와-이메일)가 여러분을 대신해 이를
  만들고 — **PDF 생성** — 첨부 파일로 보낼 수 있습니다.
