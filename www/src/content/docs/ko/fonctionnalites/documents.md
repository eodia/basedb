행 하나가 **PDF**가 됩니다: 행과 합계가 있는 청구서, 견적서, 배송 확인서, 또는 문서입니다.
행 세부 정보의 **PDF 문서** 버튼을 누르면 새 탭에서 열리고, 그 탭에서 브라우저가 인쇄하거나
저장합니다.

## 설정 없이 만드는 기본 문서

템플릿이 없으면 행은 **기본 문서**로 인쇄됩니다: 제목으로 행의 이름, 그다음 읽을 수 있는
모든 필드가 사용자 언어로 표시됩니다.

## 템플릿

테이블을 만드는 사람 — 관리 권한 — 이 행 세부 정보에서 작성합니다: **PDF 문서 › 문서
템플릿…**. 템플릿은 한 페이지(A4 또는 Letter, 세로 또는 가로), 값을 표시할 언어, 바닥글,
그리고 일련의 블록으로 이루어집니다.

| 블록 | 보여 주는 것 |
|---|---|
| **텍스트** | 서식 있는 텍스트 — 제목, 굵게, 목록, 링크 — 로, **열** 메뉴로 행의 열을 인용합니다: “청구서 `{{numero}}` — `{{date}}`” |
| **행의 필드** | 선택한 필드 전체 또는 일부: 왼쪽에 레이블, 오른쪽에 값 |
| **연결된 행 표** | 이 행을 가리키는 행들 — 청구서의 각 줄 — 이나 다중 관계가 가리키는 행들을, 선택한 열과 그 **합계**와 함께 표시 |
| **페이지 나누기** | 다음 내용을 새 페이지에서 시작 |

편집기 옆에는 템플릿이 지금 열려 있는 행을 어떻게 PDF로 만드는지, 수정 중인 내용까지 함께
보여 줍니다.

값은 **템플릿의 언어로** 표시됩니다: 통화가 붙은 금액(“1 234,50 €”), 글로 풀어 쓴 날짜
(“2026년 9월 30일”), 예와 아니요, 선택 값의 레이블, 사람의 이름입니다. 텍스트는 basedb의
20개 언어를 모두 지원하는 내장 글꼴로 구성되며, 한자·가나·한글도 예외가 아닙니다.

## 각자 자신의 권한으로

문서는 **인쇄하는 사람의 권한으로** 읽힙니다. 그 사람에게 숨겨진 필드는 나타나지 않고, 볼 수
없는 연결된 행은 표에도 합계에도 들어가지 않습니다. 그러므로 같은 행에서 두 사람이 서로 다른
두 개의 문서를 얻을 수 있습니다: 각자 자신의 문서를 받습니다.

## API로

```bash
# 템플릿으로 만든 행의 PDF, 또는 “기본 문서”
curl -H "Authorization: Bearer $TOKEN" -o facture.pdf \
  "$BASEDB/api/v1/$TENANT/data/ventes/factures/$ID/documents/$MODELE"
```

`GET …/data/{base}/{table}/documents`는 테이블의 템플릿 목록을 반환합니다.

## 제한

- 문서에 이미지(로고)나 원하는 색상을 넣을 수 없고, 머리글과 바닥글을 따로 둘 수 없습니다.
- 행 하나에 문서 하나: 여러 행을 하나의 PDF로 만들거나 자동화로 생성하는 기능은 아직
  없습니다.
