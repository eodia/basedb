위쪽 바 가운데의 **테이블, 행, 명령 검색…** 입력창을 누르면 검색이 열립니다: basedb에서 갈
수 있는 모든 곳을 위한 단 하나의 입력창입니다. **Ctrl+K**(Mac에서는 **⌘K**)는 어느 화면에서든
검색을 열고 닫습니다 — 단, 텍스트 편집기에서는 링크를 추가합니다.

## 찾아내는 것

| | |
|---|---|
| **테이블 및 개체** | 보이는 프로젝트와 데이터베이스; 테이블, SQL 뷰, 저장된 쿼리; 열린 데이터베이스에 있는 테이블의 보기(개인 보기 포함); 프로젝트에 있는 데이터베이스의 질문, 대시보드, 자동화; 테이블의 열; 열린 탭 |
| **행** | 열린 데이터베이스의 테이블에 있는 데이터 자체: 열의 텍스트, 목록의 선택지, 정확한 숫자 — 두 글자부터. 붙여 넣은 행 식별자는 그 행을 찾음 |
| **명령** | 애플리케이션이 할 수 있는 일: 데이터베이스의 스키마, 기록, 대시보드로 이동; 테이블, 질문, SQL 쿼리, 데이터베이스, 프로젝트 만들기, 템플릿으로 시작하기; 테이블로 가져오기; 마지막 쓰기 실행 취소 또는 다시 실행; 탭 닫기 또는 전환; 테마 변경; Copilot 열기; **이 페이지 링크 복사**; 설정 또는 관리 탭 열기; 로그아웃 |
| **Copilot** | Copilot에게 맡기는 자연어 질문 |

**Enter**는 선택한 결과를 엽니다: 행은 그 테이블 안, 세부 정보 화면에서 열립니다. 큰 화면에서는
오른쪽 패널에 미리보기가 표시됩니다 — 행의 값, 테이블의 열과 설명, 대시보드나 자동화의 설명
등입니다. basedb 주소를 붙여 넣으면 **이 링크 열기**가 그곳으로 데려갑니다(
[각 화면으로 가는 링크](/basedb/ko/fonctionnalites/collaboration/#각-화면으로-가는-링크) 참고).

입력창이 비어 있으면 **최근 항목**, 열린 탭, 데이터베이스의 테이블, 몇 가지 추천이 표시됩니다.

## 떠오르는 대로 입력하기

- **단어의 앞부분이나 초성으로 입력**: “새 고객”은 `새고`로, “새 테이블”은 `새테`로 찾을 수
  있습니다.
- **오타는 눈감아 줍니다** — 글자 하나를 빠뜨리거나, 중복하거나, 다른 글자로 바꾸거나, 순서를
  바꾼 경우까지, 일곱 글자가 넘는 단어라면 두 글자까지 허용됩니다 — 단, 첫 글자는 예외입니다.
- **입력한 단어는 모두 어딘가에서 발견되어야 합니다**, 이름 자체든 그것을 담고 있는 대상이든:
  `데모 고객`은 “데모: 아틀리에 루멘” 데이터베이스의 “고객” 테이블을 찾습니다. 종류를 나타내는
  말도 입력할 수 있습니다: `보기`, `자동`, `대시보드`.
- **테이블을 먼저 쓰고 그 안에서 찾을 말을 이어 쓰기**: `고객 대전`은 “고객” 테이블의 행에서
  “대전”을 찾습니다.

맨 위에는 **최상의 결과**가 표시됩니다; 자주, 그리고 최근에 연 것일수록 위로 올라옵니다. 이
기록은 브라우저 안에만 남습니다.

## 검색 범위 좁히기

입력창 아래의 아이콘들 — **모두**, **테이블 및 개체**, **행**, **명령**, **Copilot** — 은
검색 범위를 좁힙니다. 맨 앞에 붙이는 문자 하나로도 같은 일을 할 수 있습니다:

| 맨 앞에 입력 | 찾는 대상 |
|---|---|
| `#` | 테이블과 개체만 |
| `/` | 행만 |
| `>` | 명령만 |
| `?` | Copilot에게 묻는 질문 |

테이블이나 데이터베이스에서 **Tab**을 누르면 그 **안**을 찾습니다: 입력창에 그 이름이
표시되고, 검색은 그 행, 보기, 열, 명령으로만 좁혀집니다. 입력창이 비어 있으면 가장 최근에
수정된 행 20개가 표시됩니다. 입력창이 비어 있을 때 **⌫**을 누르면 거기서 빠져나오고, **Esc**는
한 단계씩 뒤로 가다가 검색을 닫습니다.

## Copilot에게 질문하기

모든 검색 결과 목록의 끝에는 **Copilot에게 질문: “…”**이 있으며, 입력한 문장이 질문처럼
읽히면 — “?”로 끝나거나, “몇”, “어떤”, “보여 줘” 등으로 시작하거나, 다섯 단어가 넘으면 — 맨
위로 올라옵니다. Copilot은 그 데이터베이스를 대상으로 열리고, 마치 직접 입력한 것처럼 질문을
받습니다. **데이터 읽기 허용**을 선택하지 않는 한 구조만 읽고 행은 읽지 않으며, 제안만 할 뿐
적용하기 전까지는 아무것도 바뀌지 않습니다. 인스턴스에 AI가 설정되어 있어야 합니다 —
[인공지능](/basedb/ko/fonctionnalites/ia/) 참고.

## 권한과 제한

검색도 화면의 다른 부분과 같은 경로를 거치며, **자신의 권한으로** 이루어집니다: 닫혀 있는
테이블이나 열은 개체 목록에도, 행 결과에도 나타나지 않습니다. 자동화는 해당 데이터베이스에
대한 **관리** 권한이 있는 사람에게만 제안됩니다.

- 행은 열린 데이터베이스, 또는 Tab으로 들어간 데이터베이스나 테이블 안에서 찾습니다: 테이블당
  세 개, 최대 스물네 개 테이블까지; 한 테이블 안에서는 스무 개까지.
- 질문, 대시보드, 자동화는 열린 프로젝트(최대 여덟 개 데이터베이스)의 것이며, 최대 2분마다
  다시 읽힙니다.
- 각 그룹은 몇 개의 결과를 보여 준 다음 **결과 N개 더 보기**를 표시하며, 누르면 전체가
  열립니다.

## 키보드 단축키

검색 하단의 **단축키**, 또는 **키보드 단축키** 명령을 실행하면 전체 목록을 볼 수 있습니다.
Mac에서는 **Ctrl**을 **⌘**로 읽습니다.

| 키 | 동작 |
|---|---|
| **Ctrl+K** | 검색 열기 또는 닫기 |
| **↑** **↓**, **Enter** | 결과 사이 이동, 결과 열기 |
| **Alt+W** | 탭 닫기 |
| **Ctrl+Tab**, **Ctrl+Shift+Tab** | 다음 탭, 이전 탭 |
| 휠 클릭 | 탭 닫기 |
| **Ctrl+A**, **Ctrl+C** | 그리드에서 전체 선택, 선택한 셀 복사 |
| **Ctrl+클릭** | 관계 따라가기 |
| **Ctrl+Z**, **Ctrl+Y** | 마지막 쓰기 실행 취소, 다시 실행 |
| **Ctrl+Enter** | 댓글 보내기, 설명 저장하기 |
| **Ctrl+B**, **Ctrl+I**, **Ctrl+K** | 텍스트 안에서: 굵게, 기울임, 링크 |
