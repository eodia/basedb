---
title: Сервер MCP
description: Підключення агента ШІ до basedb через Model Context Protocol.
---

basedb надає **сервер MCP** (`POST /mcp`, за тією самою адресою, що й інтерфейс): агент — Claude,
асистент для програмування, ваш власний агент — знаходить там бази, читає й записує рядки,
видаляє їх з вашого дозволу, та **пропонує** зміни структури.

## Підключення агента

Створіть токен у **Токени API та MCP…** (меню бази, розділ **API та агенти**), позначивши доступ MCP. Той самий токен
працює і для REST API, і для MCP.

Для клієнта, який працює через HTTP, адреса — `http://localhost:3000/mcp` із заголовком
`Authorization: Bearer <jeton>`. Для клієнта, який запускає процеси (stdio), репозиторій містить
ретранслятор, що читає токен зі змінної середовища — ніколи з конфігурації:

```bash
claude mcp add basedb -- node <dépôt basedb>/apps/mcp/dist/relay.js \
  --url http://localhost:3000/mcp --token-env BASEDB_TOKEN
```

## Чотирнадцять інструментів

| Інструмент | Призначення |
|---|---|
| `whoami` | хто цей агент і з якими дозволами |
| `list_bases`, `describe_base`, `describe_table` | дослідити структуру та її описи |
| `list_records`, `get_record`, `lookup_records` | читати, фільтрувати, знаходити рядок за значенням відображення |
| `create_record`, `update_record` | записувати рядки |
| `delete_record`, `restore_record` | видалити рядок — токеном, створеним для цього, — і повернути його |
| `propose_create_table`, `propose_add_field`, `get_proposal` | запропонувати зміну структури |

## Видалення рядків

Токен, створений із правами **Читання, запис і видалення**, дозволяє агенту видаляти рядки,
**по одному**, за їхнім `_id`. `delete_record` повертає рядок таким, яким він був, а видалення
історизується від імені токена; `restore_record` повертає рядок під тим самим `_id` — агент сам
виправляє свою помилку, а людина може зробити те саме з історії.

Агент не видаляє:

- токеном на читання або на читання й запис: відмова каже, який токен створити;
- рядок, який каскадний зв’язок забрав би разом з іншими (`TOKEN_CASCADE_FORBIDDEN`): таке
  видалення виконується в інтерфейсі, людиною, яка бачить, що воно забирає;
- кілька рядків одразу: жоден інструмент цього не робить.

## Чого агент не робить

- **Він видаляє лише з вашого дозволу**: токен, створений для цього, і лише по одному рядку.
- **Він не змінює структуру**: він її пропонує. Пропозиція чекає в **Пропозиції
  агентів…** (меню бази), де людина, яка керує структурою, схвалює або відхиляє її; без
  рішення вона спливає через 24 години.
- **Він ніколи не має більше дозволів**, ніж людина, яка створила його токен: дозволи токена
  перетинаються з її дозволами.
- Він не бачить полів, позначених як невидимі для агентів, ані баз, закритих для MCP.

Кожен виклик журналюється за формою його параметрів, але ніколи — за їхніми значеннями.
