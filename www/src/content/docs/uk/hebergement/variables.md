title: Змінні середовища
description: Усі змінні, які читає basedb, та їхні типові значення.
---

Усі вони задаються у файлі `.env` поруч із `docker-compose.yml`, який читає `docker compose`
(повний шаблон із коментарями — `.env.example`). З `docker run` передавайте їх через `-e`. **Порожнє значення означає «не задано».**

## Обов’язкові

| Змінна | Призначення |
|---|---|
| `POSTGRES_PASSWORD` | пароль контейнера PostgreSQL |
| `BASEDB_ENCRYPTION_KEY` | ключ екземпляра: підписує сеанси, шифрує секрети. `openssl rand -base64 32`, один раз назавжди |

## База даних

| Змінна | Типово | Призначення |
|---|---|---|
| `POSTGRES_USER` | `basedb` | роль PostgreSQL |
| `POSTGRES_DB` | `basedb` | база PostgreSQL |
| `POSTGRES_PORT` | `5432` | порт, відкритий на 127.0.0.1 |
| `DATABASE_URL` | контейнер `db` | ваша власна база PostgreSQL 16+ |

## Перший запуск

| Змінна | Типово | Призначення |
|---|---|---|
| `BASEDB_MIGRATE` | `1` | застосовує каталог на порожній базі |
| `BASEDB_BOOTSTRAP` | `1` | готує першого адміністратора |
| `BASEDB_TENANT` | `t4z56fq` | ідентифікатор робочого простору в URL API |
| `BASEDB_ADMIN_EMAIL` | — | адреса першого адміністратора, якого створюють під час запуску; якщо порожня, його створює перша людина, що відкриє інтерфейс |
| `BASEDB_ADMIN_PASSWORD` | згенерований, показується один раз | разом із `BASEDB_ADMIN_EMAIL` — його пароль; якщо задано, він повторно застосовується до адміністратора під час **кожного** запуску: приберіть його після входу |

## Вхід через Google, Microsoft… (OIDC)

| Змінна | Типово | Призначення |
|---|---|---|
| `BASEDB_OIDC_PROVIDERS` | — | запропоновані постачальники через кому: `google,microsoft` |
| `BASEDB_OIDC_<NOM>_CLIENT_ID`, `_CLIENT_SECRET` | — | застосунок, зареєстрований у постачальника |
| `BASEDB_OIDC_<NOM>_ISSUER` | вбудований для `google`, `gitlab` | видавець OpenID Connect |
| `BASEDB_OIDC_<NOM>_LABEL`, `_SCOPES` | залежно від постачальника | назва кнопки, запитувані області доступу |
| `BASEDB_OIDC_<NOM>_SIGNUP` | — | `off`: перший вхід не створює облікового запису |

Див. [Облікові записи та вхід](/basedb/uk/hebergement/connexion/).

## Адреси

| Змінна | Типово | Призначення |
|---|---|---|
| `BASEDB_PORT` | `3000` | порт, відкритий на 127.0.0.1: інтерфейс, `/api` і `/mcp` |
| `BASEDB_VERSION` | `latest` | тег образу `eodia/basedb` |
| `BASEDB_PUBLIC_URL` | — | публічна адреса basedb для повернення OIDC |
| `BASEDB_DOMAIN` | — | домен, який обслуговує через HTTPS проксі Caddy |
| `BASEDB_ORIGINS` | — | інші сайти, сторінки яких звертаються до API з браузера, через кому; не потрібно для інтерфейсу basedb, що обслуговується за тією самою адресою |
| `BASEDB_API`, `BASEDB_MCP` | `/`, `/mcp` | API та MCP з погляду браузера; налаштовуйте лише для середовища розробки (`pnpm start`) |

## Штучний інтелект

| Змінна | Типово | Призначення |
|---|---|---|
| `BASEDB_AI_PROVIDER` | — | `openai`, `anthropic` або `mistral` |
| `BASEDB_AI_MODEL` | — | модель |
| `BASEDB_AI_API_KEY` | — | ключ (інакше `OPENAI_API_KEY`, `ANTHROPIC_API_KEY`, `MISTRAL_API_KEY`) |
| `BASEDB_AI_QUOTA` | `120` | інтерактивних викликів на годину для кожного робочого простору |

## Публічна демоверсія

Екземпляр, відкритий для всіх, як-от [demo.basedb.eodia.com](https://demo.basedb.eodia.com):
екран входу заповнює спільний обліковий запис, відвідувач читає все й змінює те, що існує, але
нічого не створює й не видаляє — базу, таблицю, рядок, файл, коментар, обліковий запис, токен,
посилання, — а ШІ відповідає, що не бере участі в демоверсії. Консоль SQL тут лише читає.
Повернення бази до початкового стану щоночі лишається на вашій відповідальності.

| Змінна | Типово | Призначення |
|---|---|---|
| `BASEDB_DEMO` | — | `1`: екземпляр стає публічною демоверсією |
| `BASEDB_DEMO_ACCOUNTS` | — | один обліковий запис на мову, розділені комами: `fr=demo@demo.com,en=demo-en@demo.com`; екран входу заповнює той, що відповідає його мові, інакше — англійський, інакше — перший, і пропонує інші. Створіть ці облікові записи, кожен зі своїм проєктом, перш ніж вмикати демоверсію: вона відхиляє створення для всіх, зокрема для адміністратора |
| `BASEDB_DEMO_PASSWORD` | — | разом із `BASEDB_DEMO_ACCOUNTS` — їхній пароль, однаковий для всіх, опублікований разом із ними |

Без `BASEDB_DEMO_ACCOUNTS` спільним обліковим записом є адміністратор, якого визначають
`BASEDB_ADMIN_EMAIL` і `BASEDB_ADMIN_PASSWORD`. Адреса демоверсії входить з опублікованим
паролем, хоч би що ввели: невдалі спроби не блокують її для всіх.
