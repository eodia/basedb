Поле **Шукати таблиці, рядки, команди…**, у центрі верхньої панелі, відкриває пошук: одне поле
для всього, до чого ви маєте доступ у basedb. **Ctrl+K** (**⌘K** на Mac) відкриває або закриває
його з будь-якого екрана — крім текстового редактора, де він додає посилання.

## Що він знаходить

| | |
|---|---|
| **Таблиці й об’єкти** | проєкти та бази, які ви бачите; таблиці, SQL-подання та збережені запити; подання таблиць відкритої бази, зокрема особисті; запитання, інформаційні панелі та автоматизації баз проєкту; стовпці таблиць; відкриті вкладки |
| **Рядки** | самі дані, у таблицях відкритої бази: текст стовпців, варіанти списків, точне число — від двох символів. Вставлений ідентифікатор рядка знаходить свій рядок |
| **Команди** | те, що вміє застосунок: перейти до структури, історії, інформаційних панелей бази; створити таблицю, запитання, SQL-запит, базу, проєкт, почати із шаблону; імпортувати в таблицю; скасувати або повернути останній запис; закрити вкладку або перемкнутися на іншу; змінити тему; відкрити Copilot; **Копіювати посилання на цю сторінку**; відкрити вкладку налаштувань або адміністрування; вийти |
| **Copilot** | запитання природною мовою, передане Copilot |

**Enter** відкриває вибраний результат: рядок відкривається у своїй таблиці, у деталях рядка. На
великому екрані праворуч панель показує його попередній перегляд — значення рядка, стовпці й
опис таблиці, опис інформаційної панелі чи автоматизації. Вставте адресу basedb: **Відкрити це
посилання** веде вас туди (див. [посилання на кожен
екран](/basedb/uk/fonctionnalites/collaboration/#посилання-на-кожен-екран)).

Порожнє поле пропонує ваші **нещодавні**, відкриті вкладки, таблиці бази та кілька підказок.

## Пишіть, як думаєте

- **Без великих літер**: `клієнти` знаходить «Клієнти».
- **Початки слів та ініціали**: `нз` — для «Нове запитання», `новтаб` — для «Нова таблиця».
- **Одна прощена одруківка** — пропущена, подвоєна, замінена чи переставлена літера, дві — у
  слові довшому за сім літер, — але ніколи в першій літері.
- **Кожне введене слово повинно десь знайтися**, у назві або в тому, що її містить: `продажі
  клієнти` знаходить таблицю «Клієнти» бази «Продажі». Тип об’єкта теж можна ввести: `подання`,
  `автоматизація`, `інформаційна панель`.
- **Спочатку таблиця, потім те, що в ній шукають**: `клієнти львів` шукає «львів» у рядках
  таблиці «Клієнти».

Угорі — **найкращий результат**; те, що ви відкриваєте часто й нещодавно, піднімається вище. Ця
пам’ять лишається у вашому браузері.

## Звузити пошук

Кнопки-фільтри під полем — **Усі**, **Таблиці й об’єкти**, **Рядки**, **Команди**, **Copilot** —
звужують те, що шукається. Перший символ робить те саме:

| Введіть спочатку | Щоб шукати |
|---|---|
| `#` | лише таблиці й об’єкти |
| `/` | лише рядки |
| `>` | лише команди |
| `?` | запитання до Copilot |

**Tab** на таблиці чи базі шукає **всередині** неї: її назва з’являється в полі, і пошук
стосується вже лише її рядків, подань, стовпців і команд. Порожнє поле тоді показує двадцять
рядків, змінених найостанніше. **⌫** із порожнім полем виходить із цього режиму; **Esc** повертає
на крок назад, а потім закриває.

## Запитати Copilot

Кожен пошук завершується пунктом **Запитати Copilot: «…»**, який стає першим, якщо текст
читається як запитання — закінчується на «?», починається з «скільки», «який», «покажи»… або
містить п’ять слів і більше. Copilot відкривається на базі й отримує запитання так, ніби ви
ввели його самі. Він читає структуру, а не рядки, якщо тільки ви не позначите **Дозволити
читання даних**, і пропонує рішення: нічого не змінюється, доки ви його не застосуєте. Потрібно,
щоб ШІ було налаштовано на екземплярі — див. [Штучний інтелект](/basedb/uk/fonctionnalites/ia/).

## Дозволи та обмеження

Пошук проходить через ті самі маршрути, що й решта екрана, **із вашими дозволами**: таблиця чи
стовпець, закриті для вас, не з’являються — ні серед об’єктів, ні в рядках. Автоматизації
пропонуються лише тому, хто має рівень **Керування** для їхньої бази.

- Рядки шукаються у відкритій базі або в базі чи таблиці, куди ви увійшли через Tab: три рядки на
  таблицю, не більш ніж у двадцяти чотирьох таблицях; двадцять рядків у таблиці.
- Запитання, інформаційні панелі та автоматизації — це ті, що належать відкритому проєкту (не
  більш ніж вісім баз), які перечитуються не частіше ніж раз на дві хвилини.
- Кожна група показує кілька результатів, а потім **Ще N результатів**, що розгортає її повністю.

## Комбінації клавіш

**Скорочення** внизу пошуку або команда **Комбінації клавіш** показує їх усі. **Ctrl** читається
як **⌘** на Mac.

| Клавіші | Дія |
|---|---|
| **Ctrl+K** | відкрити або закрити пошук |
| **↑** **↓**, **Enter** | переглядати результати, відкрити результат |
| **Alt+W** | закрити вкладку |
| **Ctrl+Tab**, **Ctrl+Shift+Tab** | наступна вкладка, попередня вкладка |
| клацання коліщатком | закрити вкладку |
| **Ctrl+A**, **Ctrl+C** | у сітці: вибрати все, копіювати вибрані клітинки |
| **Ctrl+клацання** | перейти за зв’язком |
| **Ctrl+Z**, **Ctrl+Y** | скасувати останній запис, повернути його |
| **Ctrl+Enter** | надіслати коментар, зберегти опис |
| **Ctrl+B**, **Ctrl+I**, **Ctrl+K** | у тексті: жирний, курсив, посилання |
