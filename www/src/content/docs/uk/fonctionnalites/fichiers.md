Поля **Файл** і **Зображення** приймають файли. Самі байти **не потрапляють у
PostgreSQL**: стовпець зберігає те, що потрібно для їхнього переліку (ідентифікатор, назву, тип,
розмір), а самі файли живуть в окремому сховищі й віддаються за підписаними посиланнями.

## На диску

Типово API записує файли в каталог — в образі Docker це том `files`, змонтований у
`/data/files`. Цього достатньо для одного хоста; під час запуску API повідомляє, куди
потрапляють файли.

## В S3-сумісному сховищі

AWS, Scaleway, OVH, Cloudflare R2, Garage, SeaweedFS, MinIO…:

```bash
BASEDB_S3_BUCKET=basedb
BASEDB_S3_ENDPOINT=https://s3.fr-par.scw.cloud
BASEDB_S3_REGION=fr-par
BASEDB_S3_ACCESS_KEY_ID=…
BASEDB_S3_SECRET_ACCESS_KEY=…
# BASEDB_S3_FORCE_PATH_STYLE=0   для адресації за хостом
```

Якщо `BASEDB_S3_BUCKET` задано без інших значень, API відмовляється запускатися й повідомляє,
яких саме бракує.

## Розмір

`BASEDB_FILES_MAX_MB` обмежує розмір одного файлу (типово 25 МБ).

:::note
Опубліковані за посиланням форми не ставлять запитань типу «Файл» і «Зображення»: вони не
відкривають завантаження файлів для незнайомих людей.
:::
