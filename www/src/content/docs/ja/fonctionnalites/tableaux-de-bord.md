**ダッシュボード**は、チームが毎日見るものを1ページにまとめます。重要な数値、月ごとの推移、ステータスの内訳、次の期日などです。各カードは**質問**を表示します。質問とは、マウス操作で組み立てるかSQLで書く、データベースの読み取りです。ページ上部の**フィルター**が、それに接続されたカードを制御します。

![「Pilotage de l’agence」ダッシュボード：今月のトレンド、目標、積み上げの売上高、レビューのセンチメント](../../../../assets/screens/tableaux-de-bord.png)

すべては、サイドバー下部にある、開いているデータベースのブロックの**ダッシュボード**から開きます。左側には、データベースのダッシュボードと保存済みの質問、そして何も保存せずに質問できる**データを探索**が並びます。データベースの閲覧者は誰でも閲覧・探索できます。作成、変更、保存には**管理**レベルが必要です。

## マウス操作で質問を作る

質問は、上から順にステップを重ねて組み立てます：

![質問エディター：データ、フィルター、月ごとの集計](../../../../assets/screens/question-editeur.png)

| ステップ | 選ぶもの |
|---|---|
| **データ** | 起点となるテーブルと、集計しない場合に表示する列 |
| **データを結合** | データベース内の別のテーブル。リレーションで結ばれたもの（自動で提案されます）、または同じ種類の2つの列で結ぶもの。左結合、内部結合、右結合、完全結合 |
| **フィルター** | 列ごとに、その型に応じた条件：等しい/等しくない、含む、範囲内、空など。日付の場合は**期間**：今日、過去30日、今月、前四半期、…から…まで。またはビューのバーと同じように書く式 |
| **集計** | 指標（行数、合計、平均、中央値、最小、最大、一意の値の数、標準偏差、累計）を、1〜3個の列**ごとに** |
| **並べ替え**、**件数制限** | 行の順序と、最大件数 |

日付は**日、週、月、四半期、年ごと**に、または周期（曜日、月、時刻）ごとにまとめられます。数値は範囲ごとにまとめられます。複数選択は、各行をそれぞれの選択肢ごとに数えます。期間は自分のタイムゾーンで解釈され、週は設定で指定した曜日から始まります。

**可視化**で質問を実行します。結果は内容に合った形（数値、折れ線、棒、表など）で表示され、画面下部で変更できます：

| 可視化 | 表示するもの |
|---|---|
| **数値**、**トレンド**、**進捗**、**ゲージ** | 1つの値。直近の期間を、前の期間および前年同期と比較。目標に対する進み具合 |
| **縦棒グラフ**、**横棒グラフ**、**折れ線グラフ**、**面グラフ**、**複合グラフ** | 1つの軸に沿った指標。系列を並べて、積み上げて、または100%で表示 |
| **円グラフ**、**ファネル** | 割合、段階 |
| **散布図** | 2つの指標の対比。3つ目の指標を点の大きさで表示 |
| **表**、**クロス集計表** | 並べ替え可能な行。一方の軸を行、もう一方を列にして合計付きで表示 |
| **地図** | フランスの地域圏または県、あるいは国を値で色分け。または緯度と経度による点 |

**表示設定**で表示内容を調整でき、結果は**CSV**でダウンロードできます。

### グラフをカスタマイズする

| 可視化 | **表示設定**でできること |
|---|---|
| **棒、折れ線、面、複合** | 各系列の色と名前、積み上げ（積み上げの上に合計を表示）、棒の幅、なめらかな線または階段状の線（点の有無）、カテゴリーの順序、軸のタイトル、目盛り、ラベルの傾き、範囲、対数目盛り、グラフ上の値、目標 |
| **円グラフ** | ドーナツとその太さ、半円、ローズ、中央の合計、「その他」にまとめるまでの項目数、各項目の色と名前、項目上または横のラベル、凡例の位置 |
| **ファネル** | 各段階の色と名前、その順序 |
| **数値、トレンド、進捗、ゲージ** | 色、値に応じた色、数値の下の説明、比較（減少を良い知らせとみなすかどうかも） |
| **表、クロス集計表** | 列の名前変更と並べ替え、セル内のバー、値に応じた色（セル単位または行単位）、密度、1ページあたりの行数、行番号、合計 |
| **地図** | 色合い、地域名 |

すべての可視化で、数値の形式を設定できます：小数点以下の桁数、接頭辞と接尾辞、`1,2 k`のような省略表記。

## クリックで探索する

棒、点、扇形をクリックすると、それが表すものが開きます：

- **これらの行を表示**：その点の背後にある行を、その点が表す条件で絞り込んで表示します。
- **週ごとに詳しく見る**：期間をより細かい単位に展開します（年を四半期に、月を週に）。
- **…で分解**：同じ指標を、その点について別の列で分けます。
- **この値のみ**、**この値を除外**。

各ステップは独立した質問で、必要なら保存できます。戻る矢印で前のステップに戻ります。表の行をクリックすると、その行の詳細が開きます。

ダッシュボード上では、同じクリックで **ダッシュボードを絞り込む：「Lyon」** も提案され、対象となるカードの数が表示されます。これは**一時的な**フィルターで、保存されることはなく、フィルターバーに点線で表示され、クリックひとつで外せます。質問が同じ列を（そのテーブルから、または結合を通じて）読むすべてのカードに適用されます。この提案が出るのは、そのカードでその列にダッシュボードのフィルターがまだ接続されていない場合だけで、他にその列を読むカードがない場合はグレー表示（「このカードのみ」）になります。SQLの質問は、このフィルターの影響を受けません。

## SQLで質問を書く

**SQL質問**は、データベースのテーブルに対して、本来の名前で書く`SELECT`です。管理レベルの人も含めて全員が、**読み取り専用で、自分の権限で**実行します。閉じられたテーブルは存在せず、非表示のフィールドは拒否され、書き込みはできません。グラフなしでクエリをテーブルの下に保存したいだけの場合や、本物のPostgreSQLビューにしたい場合は、[クエリとSQLビュー](/basedb/ja/fonctionnalites/requetes-et-vues-sql/)をご覧ください。

**変数**は`{{nom}}`と書きます。値がないときに取り除く部分は、`[[`と`]]`で囲みます：

```sql
SELECT statut, count(*) AS taches
  FROM taches
 WHERE {{periode}} [[AND priorite = {{priorite}}]]
 GROUP BY statut
```

変数はテキスト、数値、日付のほか、**列フィルター**にもできます。その場合、`{{periode}}`は選んだ列（ここでは`echeance`）に対する条件全体になり、何も選ばれていなければ`TRUE`になります。これにより、ダッシュボードのフィルターで、他の質問と同じようにSQLの質問も制御できます。

## ダッシュボードをレイアウトする

**編集**で、ダッシュボードを編集モードにします：

- **質問**：保存済みの質問を配置するか、そのカード専用の質問を作成します。
- **見出し**と**テキスト**：セクションの見出しや、Markdownのテキストを追加します。
- **埋め込みページ**：`https://`のアドレスを、隔離されたフレームに表示します。セッションもデータも渡されません。
- **タブ**：カードを複数のページに分けます。ダブルクリックで、タブの名前を変更できます。

カードはハンドルで移動し、角でサイズを変更します。グリッドは24列です。**保存**で全体を保存し、**キャンセル**で以前の版に戻ります。閲覧時にカードのタイトルをクリックすると、ダッシュボードのフィルターを含めて、その質問を探索できます。

## フィルター

**フィルター**で、ダッシュボード上部にコントロールを追加します：**日付**（期間）、**カテゴリー**（チェックで選ぶ値）、**テキスト**、**数値**、または折れ線グラフを月から週や年に切り替える**日付のグループ化**。

フィルターは、接続されたカード（1枚、複数、またはすべて）を制御します。作成時には、適合する列に自動で接続されます。フィルターを選択すると、各カードでフィルター対象の列が表示され、変更や解除ができます。**対応するすべてのカードに接続**で、残りを補完します。**デフォルト値**（例：「今年」）も設定できます。

閲覧時には、点をクリックしてフィルターを設定することもできます。たとえば、都市の列が「Ville」フィルターに接続されたカードで **「Lyon」で絞り込む** を選びます。

![「Activité」タブ：ステータス別に積み上げた期日ごとのタスク、プロジェクトのファネル、見積時間のクロス集計表](../../../../assets/screens/tableaux-de-bord-activite.png)

## Copilot

ダッシュボードセクションのヘッダーにある**Copilot**を押すと、データベースについて自然言語で会話できるパネルが右側に開きます。「月ごとの売上高」「顧客のフィルターを追加して」「8月はなぜ下がっているの？」。各提案はカードとして届き、クリックひとつで適用できます：

| 提案 | 内容 |
|---|---|
| **質問** | 会話の中で実行・描画されます。エディターで開くか、ダッシュボードに追加できます |
| **ダッシュボードの変更**、または新しいダッシュボード | カードの追加・変更・削除、テキスト、その列を持つカードに自動で接続されるフィルター、タブ、名前。1回の保存で行われ、カードから**元に戻す**ことができます |
| **表示中のフィルターの値** | 「先月を見せて」：フィルターが設定されるだけで、何も保存されません |

質問したりフィルターを設定したりするのは、データベースの閲覧者なら誰でもできます。ダッシュボードの変更や作成には、**管理**レベルが必要です。

デフォルトでは、会話とともにAIプロバイダーに送られるのは**構造のみ**です：テーブルとそのフィールド、データベースのダッシュボードと保存済みの質問、そして表示中のダッシュボード（タブ、フィルター、カードの定義（質問とテキスト））。行、カードの結果、そして**フィルターで選んだ値**は送られません。これらはデータである可能性があるためで、フィルターについては、値が設定されているという事実だけが送られます。エージェントに対して非表示に設定されたフィールドは送られず、それを引用するカードの質問も送られません。

**データの読み取りを許可**にチェックを入れると、その会話の間、表示中のフィルターの値と、そのフィルターでのカードの結果が加わり（1回の読み取りにつき最大50行、回答の下に一覧表示）、数値に基づいたコメントができるようになります。[AI](/basedb/ja/fonctionnalites/ia/)をご覧ください。

## ダッシュボードを共有する

ダッシュボードのヘッダーにある**共有**は、データベースに対して**管理**レベルを持つ人が使えます。方法は2つです：

- **データベースを共有…** で、データベースに人を招待します。招待された人はbasedbでダッシュボードを開き、各カードはその人自身の権限で読まれます。
- **リンクを作成**で、この**ダッシュボードだけ**へのリンクを作ります。データベースに対する権限は不要です。

| リンクのアクセス | 閲覧できる人 |
|---|---|
| **公開** | リンクを知っている人なら誰でも（アカウント不要） |
| **ログイン済みメンバー** | ログインしたワークスペースのメンバー（必要に応じて、特定のグループのみ） |

リンク先のページには、ダッシュボードのタブ、フィルター、カードが**読み取り専用**で表示されます。探索も、行へのアクセスも、独自の質問もできません。カードは**リンクを公開した人の権限**で読まれ、その権限は読み取りのたびに改めて判定されます。その人がデータベースへのアクセスを失うと、リンクは**停止**されます。**リンク有効**のスイッチでリンクを失わずに無効化でき、**再生成**で古いリンクを無効にします。

**他のサイトへの埋め込みを許可**にチェックを入れると、ダイアログに`<iframe>`の**埋め込みコード**が表示され、イントラネットやWikiにダッシュボードを表示できます。[共有ビュー](/basedb/ja/fonctionnalites/vues-partagees/)と同じしくみです。

## 見る人それぞれの権限で

各カードは、**見ている人の権限で**読まれます。同じダッシュボードでも、各自には見る権利のあるものが表示されます。ただし共有リンクの場合は、リンクを公開した人の権限で読まれます。閉じられたテーブルやフィールドを対象とするカードには、一部が欠けたことで誤解を招く数値ではなく、「アクセスできないデータ」と表示されます。質問を保存しても、共有されるのは質問だけで、作成者が読める内容は共有されません。

## 制限事項

- 1つの質問が返すのは最大2,000行です。集計なら、ほぼ常にこれで足ります。
- 各カードは、開いたときとフィルターを変えるたびにクエリを実行します。キャッシュはありません。
- 地図の背景は、フランス本土（地域圏、県）と世界の国々をカバーしています。出典：IGN, Admin Express（Licence ouverte）、Natural Earth。
