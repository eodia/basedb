上部バーの中央にある**テーブル、行、コマンドを検索…**フィールドが、検索を開きます。basedbの中で到達できるすべてを、ひとつのフィールドにまとめたものです。**Ctrl+K**（Macでは**⌘K**）で、どの画面からでも開閉できます——ただし、テキストエディター内では、リンクを追加する操作になります。

## 見つかるもの

| | |
|---|---|
| **テーブルとオブジェクト** | 見えているプロジェクトとデータベース。テーブル、SQLビュー、保存済みのクエリ。開いているデータベースのテーブルのビュー（個人用を含む）。プロジェクトのデータベースの質問、ダッシュボード、オートメーション。テーブルの列。開いているタブ |
| **行** | 開いているデータベースのテーブルにある、データそのもの：列のテキスト、選択肢、正確な数値——2文字以上から。貼り付けた行の識別子は、その行を見つけます |
| **コマンド** | アプリでできること：構造、履歴、データベースのダッシュボードへ移動する。テーブル、質問、SQLクエリ、データベース、プロジェクトを作成する、テンプレートから始める。テーブルへインポートする。直前の書き込みを元に戻す・やり直す。タブを閉じる・切り替える。テーマを変更する。Copilotを開く。**このページのリンクをコピー**。設定または管理のタブを開く。ログアウトする |
| **Copilot** | 自然言語での質問。Copilotに送られます |

**Enter**で選んだ結果を開きます：行はそのテーブルの、その詳細で開きます。大きな画面では、右側のパネルにプレビューが表示されます——行の値、テーブルの列と説明、ダッシュボードやオートメーションの説明です。basedbのアドレスを貼り付けると、**このリンクを開く**でそこへ移動します（[各画面へのリンク](/basedb/ja/fonctionnalites/collaboration/#各画面へのリンク)を参照）。

空欄のフィールドは、**最近使ったもの**、開いているタブ、データベースのテーブル、いくつかの候補を提案します。

## 思いつくままに入力する

- **アクセント記号や大文字・小文字は区別しません**。
- **先頭だけでも**：`新しい`で「新しいテーブル」、`ダッシュ`で「ダッシュボード」が見つかります。
- **入力ミスも許容します**——文字の抜け、重複、置き換え、入れ替えが1つ、7文字を超える単語なら2つまで——ただし先頭の文字では許容されません。
- **入力した単語はそれぞれ、名前かそれを含むものの中に見つかる必要があります**：`販売 顧客`は、データベース「販売」のテーブル「顧客」を見つけます。種類を入力することもできます：`ビュー`、`オートメーション`、`ダッシュボード`。
- **テーブル名の後に検索語を続ける**：`顧客 大阪`は、テーブル「顧客」の行の中から「大阪」を検索します。

先頭には**最有力候補**が表示されます。よく開くものや最近開いたものが上位に来ます。この記憶は、お使いのブラウザーにとどまります。

## 検索を絞り込む

フィールド下のチップ——**すべて**、**テーブルとオブジェクト**、**行**、**コマンド**、**Copilot**——が、検索対象を絞り込みます。最初の1文字でも同じことができます：

| 最初に入力 | 検索対象 |
|---|---|
| `#` | テーブルとオブジェクトのみ |
| `/` | 行のみ |
| `>` | コマンドのみ |
| `?` | Copilotへの質問 |

テーブルやデータベースの上で**Tab**を押すと、**その中を**検索します：その名前がフィールドに表示され、検索対象はその行、ビュー、列、コマンドだけになります。フィールドが空のときは、直近に変更された20行が表示されます。フィールドが空の状態で**⌫**を押すと、そこから抜けます。**Esc**は一段階戻り、その後閉じます。

## Copilotに質問する

どの検索も、末尾に**Copilotに質問する：「…」**があります。テキストが質問のように読める場合——「？」で終わる、「いくつ」「どの」「見せて」などで始まる、あるいは5語以上ある場合——は先頭に表示されます。Copilotはそのデータベースで開き、その質問を入力したのと同じように受け取ります。読むのは構造だけで、行は読みません。ただし**データの読み取りを許可**にチェックを入れた場合は別です。そして提案するだけです：適用するまでは何も変わりません。インスタンスでAIが設定されている必要があります——[AI](/basedb/ja/fonctionnalites/ia/)をご覧ください。

## 権限と制限

検索は、画面の他の部分と同じ経路を通り、**自分の権限で**行われます：閲覧できないテーブルや列は、オブジェクトの中にも行の中にも表示されません。オートメーションは、そのデータベースに対して**管理**レベルを持つ人にしか提案されません。

- 行は、開いているデータベース、またはTabで入ったデータベースかテーブルの中から検索されます：テーブルごとに3行、最大24テーブルまで。テーブルの中では20行まで。
- 質問、ダッシュボード、オートメーションは、開いているプロジェクト（最大8データベース）のもので、最大2分の間隔で読み直されます。
- 各グループにはいくつかの結果が表示され、その後に**他にN件の結果**が続きます。これを選ぶと、そのグループがすべて開きます。

## キーボードショートカット

検索欄下部の**ショートカット**、またはコマンド**キーボードショートカット**で、そのすべてを表示できます。**Ctrl**はMacでは**⌘**と読み替えてください。

| キー | 効果 |
|---|---|
| **Ctrl+K** | 検索を開く・閉じる |
| **↑** **↓**、**Enter** | 結果を移動する、結果を開く |
| **Alt+W** | タブを閉じる |
| **Ctrl+Tab**、**Ctrl+Shift+Tab** | 次のタブ、前のタブ |
| ホイールクリック | タブを閉じる |
| **Ctrl+A**、**Ctrl+C** | グリッド内で、すべて選択する、選んだセルをコピーする |
| **Ctrl+クリック** | リレーションをたどる |
| **Ctrl+Z**、**Ctrl+Y** | 直前の書き込みを元に戻す、やり直す |
| **Ctrl+Enter** | コメントを送信する、説明を保存する |
| **Ctrl+B**、**Ctrl+I**、**Ctrl+K** | テキスト内で：太字、斜体、リンク |
