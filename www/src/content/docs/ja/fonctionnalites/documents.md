title: PDFドキュメント
description: 行を請求書、見積書、印刷用の書類にします。関連する行とその合計も含めて。
---

行は**PDF**になります：明細と合計のある請求書、見積書、納品書、書類。行の詳細にある**PDFドキュメント**ボタンで新しいタブに開き、ブラウザーから印刷または保存できます。

## 既定の書式

テンプレートがない場合、行は既定の書式で印刷されます：見出しに行の名前、続いて閲覧できるすべてのフィールドが、あなたの言語で記載されます。

## テンプレート

テーブルを構築する人——**管理**レベル——が、行の詳細から作成します：**PDFドキュメント › ドキュメントテンプレート…**。テンプレートは、1つのページ（A4またはLetter、縦または横）、値を表示する言語、フッター、そしてブロックの並びからなります：

| ブロック | 表示内容 |
|---|---|
| **テキスト** | 見出し、太字、リスト、リンクを含むリッチテキスト。**列**メニューで行の列を引用できます：「請求書`{{numero}}`（`{{date}}`）」 |
| **行のフィールド** | 選んだフィールド、またはすべて：左にラベル、右に値 |
| **リンクされた行の表** | この行を指す行——請求書の明細行——か、複数リレーションが指す行を、選んだ列とその**合計**とともに表示 |
| **改ページ** | 続きを新しいページに |

エディターには、開いている行についてそのテンプレートが作るPDFが、編集内容を反映しながら横に表示されます。

値は**テンプレートの言語で**書かれます：金額はその通貨で（「1 234,50 €」）、日付は書き言葉で（「30 septembre 2026」）、はい・いいえ、選択肢のラベル、人の名前。テキストは、basedbの20言語すべて——表意文字を含む——をカバーする組み込みフォントで組まれます。

## 各自の権限で

ドキュメントは**印刷する人の権限で**読まれます：その人に非表示のフィールドは載らず、その人が見られないリンク先の行は表に含まれません——合計にも入りません。したがって、同じ行から2人が異なるドキュメントを得ることがあります：それぞれが自分の内容を持ちます。

## APIから

```bash
# テンプレートを使った行のPDF。テンプレートがなければ既定の書式
curl -H "Authorization: Bearer $TOKEN" -o facture.pdf \
  "$BASEDB/api/v1/$TENANT/data/ventes/factures/$ID/documents/$MODELE"
```

`GET …/data/{base}/{table}/documents`は、そのテーブルのテンプレートを一覧します。

## 制限事項

- ドキュメントに画像（ロゴ）や色の指定はできず、フッターと別のヘッダーもありません。
- 1行につき1ドキュメント：複数行のPDFや、オートメーションによる生成にはまだ対応していません。
