行は**PDF**になります：明細と合計のある請求書、見積書、納品書、商品シート、証明書。行の詳細にある**PDFドキュメント**ボタンで新しいタブに開き、ブラウザーから印刷または保存できます。

## 既定の書式

テンプレートがない場合、行は既定の書式で印刷されます：見出しに行の名前、続いて閲覧できるすべてのフィールドが、あなたの言語で記載されます。

## テンプレートを作成

テーブルを構築する人——**管理**レベル——が、行の詳細から<strong>PDFドキュメント › ドキュメントテンプレート…</strong>でテンプレートを作成します。新しいテンプレートは、**起点**から始まります：

| 起点 | 用意される内容 |
|---|---|
| **請求書** | ロゴと連絡先を含むヘッダー、「請求書」の文字、番号と日付、取引先、請求項目とその合計、税抜／税込の集計、お支払い条件、フッターの法的表記 |
| **見積書** | 色付きバナー上の見出し、グリッド状の情報、サービス内容、有効期間、「承認」欄 |
| **シート** | 全幅の大きな見出し、画像フィールドの写真、グリッド状のフィールド、長文のテキスト |
| **証明書** | 枠で囲まれた横向きのページ、中央揃えのテキスト、署名 |
| **空白のページ** | タイトルと行のフィールド |

**テーブルの列**——番号、日付、金額、写真、リンクされた行——をもとに作られ、テーブルにない列は単に省かれます。その後すべて変更でき、右側の**プレビュー**には、開いている行のPDFが表示され、変更するたびに更新されます。

## 内容：ブロック

ブロックは上から下へ並びます。**ハンドルをドラッグ**して並べ替え、クリックして設定を開きます。

| ブロック | 表示内容 |
|---|---|
| **見出し** | 大きな見出しとサブタイトルです。シンプルに、色付きで、下線付きで、またはページの端まで届くバナー上に表示できます |
| **テキスト** | 見出し、太字、リスト、リンクを含むリッチテキストで、**列**メニューで行の列を引用できます：「請求書`{{numero}}`（`{{date}}`）」。左揃え・右揃え・両端揃え、色付き背景、枠囲み、またはアクセントの線付きにできます |
| **画像** | ロゴ、スタンプ、または行の画像フィールドの写真です |
| **行のフィールド** | 選んだフィールド、またはすべて：左にラベル、2列または3列のグリッドで上にラベル、または**集計**——値を右揃えにし、最後の値（支払金額）を太字で表示します。空のフィールドは隠せます |
| **リンクされた行の表** | この行を指す行——請求書の明細行——か、複数リレーションが指す行を、**合計**とともに表示します。色付きヘッダー、1行おきの色付け、ヘッダー・幅・列の配置は自由に調整できます（「数量」に対して「数」など） |
| **列** | 2列または3列を横に並べ、それぞれにブロックを配置できます：一方に「請求先」、もう一方に参照情報 |
| **区切り線**、**スペース** | 線——署名用には短く——または余白です |
| **改ページ** | 続きを新しいページに |

## スタイルとページ

- **アクセントカラー**——あなたのブランドカラーです：見出し、バナー、表のヘッダー、リンクに使われます。その上の文字は、読みやすいほうに応じて白か濃い色になります。
- **文字の色**、本文と見出しの**フォント**（ゴシック体または明朝体）、文字の**サイズ**、小見出しのスタイル。
- **用紙**（A4またはLetter）、**印刷の向き**、**余白**、ページを囲む一重または二重の**枠**、**縦方向の中央揃え**——証明書向けです。
- **値の言語**：金額はその通貨で（「1,234.50€」）、日付は書き言葉で（「2026年9月30日」）、はい・いいえ、選択肢のラベル、人の名前が表示されます。テキストは、basedbの20言語——表意文字を含む——をカバーする組み込みフォントで組まれます。

## ヘッダーとフッター

**ヘッダー**には**ロゴ**——アップロードした画像（PNG、JPEG、またはSVG形式。サイズが大きすぎる画像は縮小されます）、または行の画像フィールド——と、左側のテキスト（連絡先）、右側のテキスト（文書の種類、番号、日付）が入ります。1ページ目だけ、またはすべてのページに表示できます。**フッター**には法的表記とページ番号が入ります。どちらも、テキストと同様に行の列を引用できます。

## 各自の権限で

ドキュメントは**印刷する人の権限で**読まれます：その人に非表示のフィールドは載りません——テキストにも、画像にも——、その人が見られないリンク先の行は表に含まれません——合計にも入りません。したがって、同じ行から2人が異なるドキュメントを得ることがあります：それぞれが自分の内容を持ちます。

## APIから

```bash
# テンプレートを使った行のPDF。テンプレートがなければ既定の書式
curl -H "Authorization: Bearer $TOKEN" -o facture.pdf \
  "$BASEDB/api/v1/$TENANT/data/ventes/factures/$ID/documents/$MODELE"
```

`GET …/data/{base}/{table}/documents`は、そのテーブルのテンプレートを一覧します。

## 制限事項

- 送信する画像は300KBまで、1テンプレートにつき8枚まで使えます。フィールドの画像は、PNGまたはJPEGならそのまま使われます。
- リンクされた行の値を表の外で引用するには、ドキュメントのテーブルに**ルックアップ**を作成します。税込合計はそのテーブルのフィールドです。
- 1行につき1ドキュメントです：複数行のPDFにはまだ対応していません。[オートメーション](/basedb/ja/fonctionnalites/automatisations/#pdfとメール)なら、**PDFを生成**でこれを行い、添付ファイルとして送信できます。
