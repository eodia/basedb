このチュートリアルは10分ほどで、基本をひととおり押さえられます。終わるころには、テーブル、カンバンビュー、そしてそのテーブルに書き込む公開フォームができあがっています。

:::tip[すべてを一度に見るには]
空のプロジェクトでは**デモデータベース**を作成できます。小さなエージェンシーの顧客、プロジェクト、タスク、請求書、レビューが入っており、数式、あらゆる種類のビュー、ダッシュボード、オートメーションも含まれています。**新しいデータベース**からは[テンプレートギャラリー](/basedb/ja/fonctionnalites/modeles/)も開けます。ここでは、作りたいデータベースをAIに説明することもできます。
:::

## 1. データベースを作成する

すべては**プロジェクト**単位で整理されます。サイドバー上部のセレクターで、プロジェクトを切り替えたり新しく作成したりできます。サイドバーでは、フィルターの右にある **+** でデータベースを作成します。ラベル（「Ventes」など）を付け、必要に応じて説明、色、アイコンを設定します。

データベースは**PostgreSQLスキーマ**になります。その物理名（`b_t4z56fq_ventes`）は、フォームと生成されるドキュメントに表示されます。

## 2. テーブルとフィールドを作成する

データベースの **⋯** メニューから**新しいテーブル**を選びます。続いて、同じメニューにある**スキーマ**を開き、**フィールド**ボタンからフィールドを追加します：

| フィールド | 型 |
|---|---|
| Nom | 短文テキスト |
| Statut | 単一選択 — Nouveau、Qualifié、Gagné、Perdu |
| Montant | 通貨 |
| Échéance | 日付 |
| Client | リレーション → Clients |
| Notes | 長文テキスト（Markdown） |

あとから、数式（`JOURS([Échéance]; AUJOURDHUI())`）、ルックアップ（顧客の都市）、ロールアップ（顧客ごとの合計金額）も同じ方法で追加できます。[テーブルとフィールド](/basedb/ja/fonctionnalites/tables-et-champs/)をご覧ください。

CSVまたはJSONの**ファイルをインポート**することもできます。インポートは型を推測し、修正の機会を与えたうえで、テーブルを新規作成するか既存のテーブルに追加し、受け付けなかった内容を行ごとに示します。

![データベースのメニュー](../../../../assets/screens/menu-base.png)

## 3. 入力とフィルター

グリッドはスプレッドシートのように編集できます。ダブルクリックまたはEnterでセルを編集し、Escでキャンセルします。**フィルター**はフィールドごとの条件を組み合わせます。並べ替えは列ヘッダーから行います。バーの右にある **検索…** は、すべての列を対象に検索します。変更はすべて即座に保存され、[履歴に記録](/basedb/ja/fonctionnalites/historique/)されます。**Ctrl+Z**で直前の変更を元に戻せます。

## 4. ビューを追加する

ビューセレクターは「フィルター」の左にあり、「すべての行」に続いて作成したビューが並びます。「Statut」でグループ化した**カンバン**を作成しましょう。カードを列から列へドラッグすると、その行が更新されます。

![ステータス別のカンバン](../../../../assets/screens/kanban.png)

## 5. フォームを共有する

**フォーム**ビューを作成し、質問にチェックを入れてから**共有**を選びます。「公開」を選んで、リンクをコピーします。回答ごとにテーブルに行が1つ追加され、回答者には何の権限も与えられません。詳しくは[共有フォーム](/basedb/ja/fonctionnalites/formulaires-partages/)をご覧ください。

## 6. SQLで読む

データベースの **⋯** メニュー → **新しいSQLクエリ**：テーブルが本来の名前のまま並んでいます。

```sql
SELECT nom, statut, montant
FROM b_t4z56fq_ventes.opportunites
WHERE statut = 'gagne'
ORDER BY montant DESC;
```

**保存**すると、クエリはテーブルの下の「クエリ」セクションに保存されます（自分用、またはデータベース全体用）。さらに **⋯** → **SQLビューを作成…** で、テーブルと並んで表示される本物のPostgreSQLビューにできます。どちらも、各自が自分の権限で読みます。[クエリとSQLビュー](/basedb/ja/fonctionnalites/requetes-et-vues-sql/)をご覧ください。

`psql`やBIツールからでも同じです。[直接SQL](/basedb/ja/integrations/sql/)をご覧ください。
